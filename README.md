# Nix Workshop — Windows Beta

Nix Workshop by Nixworks is a local-first coding assistant for VS Code using Ollama.

Download the v0.0.4-beta VSIX from the repository's **Releases** page. Install it using VS Code's **Extensions > Install from VSIX** command.

Requirements: Windows, VS Code, Ollama running locally, and a downloaded compatible coding model.

The beta offers local chat, code context, proposed edits with VS Code diffs, approval before applying changes, and missing-model recovery.

Use a disposable or backed-up project. This release has not completed clean-machine or full lifecycle qualification. Inline autocomplete and autonomous agent mode are future work, not beta features.

See [BETA_TEST.md](BETA_TEST.md) for a ten-minute manual test and privacy-safe feedback checklist. File bug reports in this repository's Issues section. Do not post private source, credentials, or sensitive logs.
